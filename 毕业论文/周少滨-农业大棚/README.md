## 二、系统方案（与论文内容一致）

STM32F103C8T6 主控；DHT11 测空气温湿度；SGP30（I2C）测 eCO2 / TVOC；GL5506 光敏电阻
经 ADC 测光照；YL-69 测土壤湿度；ZTS-3000 系列 pH 传感器测土壤酸碱度；0.96 寸 SSD1306
OLED + 四个独立按键构成本地交互；三路电磁继电器分别驱动风扇、雾化加湿器与灌溉水泵，
LED 补光灯与有源蜂鸣器用于补光与报警；ESP8266 以 AT 指令接入 WiFi，与手机 APP / 云平台
双向通信。系统提供自动（阈值 + 滞环回差）与手动两种工作模式。
