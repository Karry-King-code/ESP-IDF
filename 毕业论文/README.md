## 二、文档结构

**任务书**（严格对齐学校模板）：顶部"广州南方学院毕业论文（设计）任务书"标题 + 带框线四行信息表

**开题报告**：一、选题依据（目的、意义、国内外现状与发展趋势、14 条参考文献）；
二、研究内容（具体设计内容 + 表 1 硬件资源与接口分配 + 重点解决的 7 个问题 + 预期结果）；
三、研究/设计方案（10 种设计方法、11 步技术路线、6 类技术问题及对策）；
四、研究计划与进度安排；五、预期效果与主要困难；末页为指导教师、专业负责人、院系意见栏。

## 四、如何修改

正文统一以 Markdown 维护，改完重新生成 Word 即可，避免在 Word 里逐段调格式：

```
content/taskbook.md      任务书正文
content/proposal.md      开题报告正文
tools/build_docx.py      Markdown → docx（宋体小四、1.5 倍行距、首行缩进 2 字符）
tools/figs.py            重新生成 figures/*.png
```

```powershell
python tools/figs.py         # 需要时重画插图
python tools/build_docx.py   # 重新生成两份 docx
```

Markdown 支持的扩展标记：`[H1C]`（居中加粗章节标题）、`[SUB]`（左对齐小标题）、`[RED]`（红色模板提示）、
`[IMG:路径|宽度cm|图题]`、`[TCAP:表题]`、`[TW:列宽…]`（表格列宽）、`[PAGEBREAK]`、`[BLANK]`、
`[SIGN:签名|日期]`、`[RIND]`（右缩进签名行）、`{{1}}` 或 `{{11,12}}`（上标引用）。
